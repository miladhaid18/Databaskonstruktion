Bygg själv – plan till december

Om AI skrev koden är det inte konstigt att den känns främmande. Muskelminnet byggs genom att skriva själv, i små steg som körs – inte genom att läsa en färdig app.

Samma sak som 7×8

Du lärde dig gångertabellen genom att göra den många gånger, inte genom att läsa om den. Här är motsvarigheten:

  • Skriv, kör, förstör, laga. Varje steg ska vara så litet att du kan testa det direkt.
  • Förklara högt efter varje steg. Kan du inte förklara det äger du det inte.
  • Skriv om från minnet dagen efter. Det är repetitionen som gör det snabbt.
  • AI först efteråt: skriv själv först, be sedan om rättning – inte färdig kod.
Följ samma ordning som uppgifterna: struktur → enkel tabell → komplex tabell → sök/dropdown → insert/update/procedur. Varje steg bygger på det förra.

6 veckor, 30–45 min/dag

Bocka av efterhand. Kryssen sparas i webbläsaren.

Vecka 1 – Databasen från noll

  • 1. CREATE DATABASE ovning; skapa Person; INSERT 3 rader; SELECT; WHERE; UPDATE; DELETE.
  • 2. Två tabeller med FK; JOIN; LEFT JOIN; COUNT/AVG.
  • 3. PK/FK/UNIQUE/CHECK – testa att bryta varje constraint.
  • 4. Loggtabell + AFTER INSERT-trigger; testa att den skriver en rad.
  • 5. Procedur som flyttar en rad (DELETE/INSERT/DELETE) eller räknar AVG; CALL.
  • 6. Index + EXPLAIN; skapa användare + GRANT SELECT.
  • 7. Skriv trigger + procedur ur minnet; förklara högt.

Vecka 2 – PHP från Hello World

  • 1. hello.php: echo + lite HTML.
  • 2. PDO-anslutning; SELECT ett värde; sätt felmode exception.
  • 3. Person-tabell med foreach över resultatet.
  • 4. Sökformulär + prepare/bindValue/execute med LIKE.
  • 5. Dropdown som fylls från databasen + filtrering.
  • 6. INSERT-formulär med validering och execute([...]).
  • 7. Skriv sök + insert ur minnet.

Vecka 3 – PHP komplex tabell + CRUD

  • 1. JOIN-fråga till en platt tabell.
  • 2. Nästlad tabell med $prev/$prevObs.
  • 3. UPDATE med prepared statement.
  • 4. CALL + closeCursor().
  • 5. Allt i en självrefererande sida (som PHP-appen).
  • 6. 60-sekundersmanus för varje flöde, högt.
  • 7. Mock: 3 slumpade frågor.

Vecka 4 – MVC från noll

  • 1. dotnet new mvc; kör; lägg till controller + vy som visar "Hello".
  • 2. Modell med anslutning + SELECT 1; visa värdet i vyn.
  • 3. Person-tabell: DataAdapter → DataSet → ViewBag → foreach.
  • 4. Sökformulär + parameteriserad LIKE.
  • 5. INSERT: MySqlCommand + AddWithValue + RedirectToAction.
  • 6. UPDATE + dropdowns från databasen.
  • 7. Skriv sök + insert ur minnet.

Vecka 5 – MVC komplex tabell + helhet

  • 1. JOIN-fråga med flera tabeller.
  • 2. Nästlad tabell med prev.
  • 3. Arkivera: ActionLink → controller → modell → CALL.
  • 4. Layout, länkar, PathBase, TempData.
  • 5. PHP vs MVC: samma databas, olika struktur.
  • 6. Mock 1.
  • 7. Mock 2.

Vecka 6 – bara mock och svaga punkter

  • 3 slumpade frågor per dag, 5 min var, utan anteckningar.
  • Spela in dig själv och lyssna – var var det luddigt?
  • Repetera bara det som var fel; inget nytt material.

12 mönster du ska kunna skriva ur minnet

Det här är din "gångertabell". Skriv varje mönster 3 gånger från minnet, olika dagar.

  1. PDO-anslutning + felmode.
  2. prepare + bindValue + execute för SELECT.
  3. foreach över resultat → HTML-tabell.
  4. INSERT med execute([...]).
  5. CALL + closeCursor().
  6. MySqlConnection + Open + using.
  7. MySqlDataAdapter + DataSet + Fill + returnera DataTable.
  8. MySqlCommand + AddWithValue + ExecuteNonQuery.
  9. Controller Index: hämta data → ViewBag → return View().
  10. Vy: form med Url.Action, tabell med foreach.
  11. RedirectToAction efter insert/update.
  12. Trigger AFTER INSERT som loggar + procedur som flyttar en rad.

Första 30 minuterna – gör nu

CREATE DATABASE ovning;
USE ovning;
CREATE TABLE Person(
  PersonId INT PRIMARY KEY,
  Namn VARCHAR(50) NOT NULL
);
INSERT INTO Person VALUES (1, 'Erik'), (2, 'Maria'), (3, 'Olof');
SELECT * FROM Person;
SELECT * FROM Person WHERE Namn LIKE '%ar%';
UPDATE Person SET Namn = 'Maria L' WHERE PersonId = 2;
DELETE FROM Person WHERE PersonId = 3;

Efter varje rad, säg högt vad den gör: skapar struktur, skriver, läser, filtrerar, ändrar, tar bort. Det är grunden allt annat bygger på.

Imorgon: lägg till en till tabell med FK och en JOIN. Dagen efter: en trigger. Ett steg per dag.

Regler för AI-hjälp

  • Skriv först – även om det blir fel. Fråga sedan: "varför är detta fel?".
  • Be om ledtråd, inte lösning: "vilket nyckelord saknas?" i stället för "skriv koden".
  • Skriv om från minnet dagen efter. AI:s kod räknas inte som din förrän du kan återskapa den.
  • Förklara högt innan du frågar – då ser du själv var det tar stopp.
Sparas lokalt i webbläsaren. Ett litet steg per dag slår tio långa pluggdagar i december.
