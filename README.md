# IT429G Databaskonstruktion

Publikt arkiv med kursmaterial för **IT429G Databaskonstruktion**. Omtenta: **18 december 2026**.

## Innehåll

- `Databaskonstruktion/` – anteckningar, gamla tentor, lärarmaterial och studieplan.
- `databaskonstruktion-assignment-1-startup/` – SQL-databas och ER-diagram.
- `PHP databaskonstruktion-assignment-2-startup/` – PHP/PDO-applikation.
- `databaskonstruktion-assignment-3-startup/` – ASP.NET Core MVC-applikation.
- `Alla 3 delmoment/` och `alla delmoment kod filer/` – samlade delmoment.
- `tentatraning/` – repetitionsmaterial.
- `notebooklm/ALLT.md` – sammanställd kurskärna för NotebookLM.

## Viktigt

- Alla lösenord och connection strings är ersatta med `<REDACTED>`.
- Koden är inte avsedd att köras direkt mot en produktionsdatabas. Skapa egna lokala användare och lösenord.
- Tentor och lärarmaterial publiceras med skriftligt tillstånd; se `NOTICE.md`.
- Repot innehåller även XAMPP-standardfiler och andra projekt; de är inte en del av kursen.
